# LAST SECOND

로우폴리 3인칭 투사체 회피 게임. 고요한 폐허 한 맵에서 한 번도 맞지 않고 살아남은 시간으로 경쟁합니다.

## 실행

```sh
npm install
npm run dev -- --port 5177
```

브라우저에서 http://localhost:5177 을 엽니다. 데스크톱 키보드와 WebGL을 지원하는 브라우저가 필요합니다.

## 조작

- WASD: 이동 (화면 방향 기준)
- Space: 점프. 착지 후 다시 사용할 수 있습니다.
- ← / → 또는 화면의 좌우 화살표: 북 → 동 → 남 → 서 순서로 시점을 90도씩 전환합니다. 약 0.32초 동안 부드럽게 회전한 뒤 정확히 다음 방향에 멈춥니다. 빠르게 여러 번 누르면 90도 회전을 순서대로 실행하며, 키를 길게 눌러도 한 번만 전환됩니다.
- F: 이동 방향으로 약 6.8m 점멸. 정지 중에는 마지막 이동 방향으로 점멸. 재사용 30초, 짧은 무적.
- Esc: 일시정지 / 계속. 창이 비활성화되면 자동으로 일시정지합니다.

## 규칙

피격 한 번으로 종료됩니다. 경기장 밖으로 이동할 수 없고 장식물은 경계 밖에 있습니다. 공격 전 포탑이 빛나며, 충격파와 운석에는 별도 경고가 표시됩니다. 화면 밖에서 다가오는 투사체는 가장자리의 화살표로 방향을 알려줍니다.

| 생존 시간 | 새 공격 |
| --- | --- |
| 0초 | 직선탄 |
| 20초 | 부채꼴 탄막 |
| 40초 | 초기 2.5초간 방향을 추적하는 유도탄 |
| 60초 | 점프로 뛰어넘거나 점멸로 피하는 원형 지면 충격파 |
| 80초 | 바닥 경고 후 2초 뒤 낙하하는 운석 |
| 100초 이후 | 모든 공격, 계속 증가하는 발사 속도와 탄속 |

기록은 플레이어 이름과 함께 현재 브라우저의 localStorage에 상위 10개까지 저장됩니다. 인터넷 공용 순위표나 멀티플레이 서버는 포함되어 있지 않습니다. 이름은 화면에 안전한 텍스트로 표시합니다.

## 확인

```sh
npm test
npm run build
```

개발 서버에서 `?test=1`을 붙이면 자동 검증용 `window.__game`이 노출됩니다. 프로덕션 빌드에서는 비활성화됩니다.
